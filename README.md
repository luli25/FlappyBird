🐦 Flappy Bird
A classic Flappy Bird clone built with clean architecture principles, featuring Object Pooling and the Singleton design pattern for optimized performance and resource management.

📖 Description
This project is a faithful recreation of the iconic Flappy Bird game. The player controls a bird by tapping or pressing a key to navigate through an endless series of pipes without crashing. The game tracks your score and gets progressively more challenging as you play.
This project also uses object pooling and Singleton design pattern.

🎮 How to Play

Press Space / Click / Tap — Make the bird flap
Avoid the pipes — Don't hit them or the ground
Score points — Each pipe you pass through counts as one point
